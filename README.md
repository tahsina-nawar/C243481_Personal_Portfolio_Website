# Personal Portfolio Website

Features
- Responsive Design: Adapts to desktop, tablet and mobile screens.
- Navigation Bar: Includes About, Experience, Projects and Contact sections.
- Mobile Navigation: Hamburger menu for smaller screens.
- Project Showcase: Displays projects with images, descriptions and Live Demo buttons.
- Hover Effects: Interactive card and button effects.
- Contact Section: Email input field with a Submit button.
- Font Awesome Icons: Icons for social media and other interface elements.

Technologies Used
- HTML
- CSS
- JavaScript
- Font Awesome
